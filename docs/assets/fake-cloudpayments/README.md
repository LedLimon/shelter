# Скриншоты эмулятора CloudPayments (PAY-1)

Страницы из задачи [PAY-1](https://github.com/LedLimon/shelter/issues/51): эмулятор платёжного виджета для разработки и CI (`PAYMENT_PROVIDER=fake`). Сняты на dev-сервере (кружок «N» внизу — индикатор `next dev`); почта и номера заказов — тестовые. Обработчика вебхуков на момент съёмки нет (PAY-3), поэтому сайт отвечает на уведомления HTTP 404, и эмулятор это показывает. Как устроен эмулятор — [docs/payments.md](../../payments.md#эмулятор-fakecloudpayments).
