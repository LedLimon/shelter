# Скриншоты писем (EMAIL-1)

Письмо-благодарность и превью из задачи [EMAIL-1](https://github.com/LedLimon/shelter/issues/55). Сняты в Chromium с превью `/dev/email` на данных-примерах из `src/server/email/emails/donation-thanks.tsx`; суммы, названия сборов и адреса на них выдуманные. Шрифты — те, что почтовая программа нашла бы на macOS; в других системах заголовки и суммы набраны своим узким гротеском. Как это устроено — [docs/design.md](../../design.md#письма) и [docs/architecture.md](../../architecture.md#письма).
