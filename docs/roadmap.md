# Роадмап

Работа ведётся задачами в [GitHub Issues](https://github.com/LedLimon/shelter/issues), сгруппированными в эпики (под-задачи) и вехи по фазам. Ссылки на эпики добавляются после их создания.

| Фаза | Цель | Оценка |
|---|---|---|
| **0 — Фундамент** | Оргвопросы и юридическое (параллельно), каркас проекта, дизайн-система, БД, авторизация, загрузка медиа, CI, staging | ~1–1.5 нед. |
| **1 — MVP: прозрачный сбор** | Собаки, нужды, пожертвования (разовые и ежемесячные в общий фонд), книга операций, прозрачность, контент, юридические страницы, запуск | ~4–6 нед. |
| **2 — Доноры и опека** | Личный кабинет, виртуальная опека, помощь вещами, ежемесячные отчёты, «Они дома» | ~4 нед. |
| **3 — Сообщество** | Волонтёрство, доступность, нагрузка | ~4–6 нед. |
| **Бэклог идей** | Telegram, личные сборы, удвоение, сертификаты, подборки, QR, «Ваш вклад за год», тест «какая собака подходит», VK ID / Яндекс ID | — |

Порядок внутри фазы определяется зависимостями задач («blocked by»): агент берёт задачу, только если все блокирующие закрыты.
