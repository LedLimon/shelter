# 0005. Пристройство: только контакты куратора, без анкеты

- Статус: Принято
- Дата: 2026-10-08

## Контекст
Приют пристраивает собак через личное общение куратора с кандидатом. Анкета с воронкой статусов — лишняя работа для маленькой команды и лишние ПДн.

## Решение
- Кнопка «Хочу забрать» на профиле собаки открывает шторку с каналами куратора (Telegram / WhatsApp / MAX / VK / телефон; набор настраивается, т.к. доступность мессенджеров в РФ меняется). Телефон раскрывается по клику.
- Клики считаются по каналам без ПДн (`AdoptClick`: собака, канал, хэш сессии с суточной ротацией соли, UTM) — чтобы видеть интерес к собакам.

## Последствия
- Минимум ПДн и кода; нет воронки в админке.
- Нельзя измерить конверсию «клик → пристройство» автоматически — куратор отмечает статус собаки «Дома» вручную.

## Рассмотренные альтернативы
- Анкета усыновителя + воронка в админке — можно вернуться к этому позже отдельным ADR.
