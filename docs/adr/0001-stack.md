# 0001. Стек: Next.js + TypeScript + Prisma + PostgreSQL

- Статус: Принято
- Дата: 2026-10-08

## Контекст
Нужен быстрый, хорошо индексируемый публичный сайт (SEO, репосты) и полноценная админка; команда маленькая, разработка во многом силами ИИ-агентов — важны популярность стека и строгая типизация.

## Решение
- Next.js (App Router) + TypeScript strict — один проект для публичного сайта, админки и API.
- Tailwind CSS v4 + shadcn/ui — дизайн-система без тяжёлых UI-библиотек.
- PostgreSQL 16 + Prisma; денежные инварианты — триггерами в raw SQL миграциях.
- Better Auth — сотрудники (пароль + TOTP), доноры (код на email).
- pg-boss — фоновые задачи на том же Postgres (без Redis), отдельный процесс `worker`.
- Vitest + Testcontainers + Playwright.
- Версии Node/pnpm — в `mise.toml`.

## Последствия
- Один репозиторий и один язык для всего; агенты хорошо знают этот стек.
- Server Components + ISR дают быстрые публичные страницы.
- Нужен Node-хостинг (не статический) — см. ADR-0004.

## Рассмотренные альтернативы
- Supabase — удобно, но облако вне РФ (ПДн) и привязка к вендору.
- Отдельный бэкенд (NestJS) + SPA — больше кода и инфраструктуры без явной пользы для одного приюта.
